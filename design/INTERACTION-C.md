# 简洁阅读与收藏

建议以标题、两行原文摘要和收藏按钮展示；详情先显示完整“说人话”，点击“查看原文”才展开成本、证据、收益、备注、来源与引用。正文数字、措辞和内容不改写，不使用 AI。

## 操作规则

底部入口为首页、检索、收藏、阅读包、关于。「阅读包」是主包独立 Tab，直接展示 PDF 阅读包、样张与购买说明；真实支付未开通时购买禁用，浏览器仅提供模拟领取。关于页不再重复设置阅读包入口。移除行动清单页面、今天待做、稍后、完成状态、行动统计、更多行动和撤销组件。首页展示推荐阅读，推荐不再受历史清单记录影响。

首页顶部为紧凑书名栏，搜索、推荐与处境分类独立成区，全书目录提供章节和专题长文两个分类，各自保留搜索条件和滚动位置。首页不再铺开专题文章；浅暗主题共用 C 风格变量。

进入章节后，先显示标题与建议条目。长篇节首导读和分组导航移入默认收起的「本节导读」，按需展开，完整原文与交叉引用保留。

展开导读后分为「本节说明」与「主题导航」。重复的主题原文不再铺开；导航按主题分成编号卡片，每条独占一行，点击定位建议。完整原文导读在导航下方按需展开，措辞、数字与链接完整保留。

离线管理集中到「关于 → 离线与更新」。下载、进度及完成度只计算章节与专题长文；保留本机内容和收藏，清理操作在次级缓存管理中。页面显示内容日期和最近检查时间，不暴露 commit、技术状态、构建统计和同步历史。浏览器仅展示说明，原生操作在小程序验证。

关于仅提供阅读帮助、离线与更新、原作与说明。阅读帮助为本小程序实际功能说明，原书术语与标注释义保持原样；删除安装 AI skill、其他阅读器/导出及网页版说明。核实记录与引用对照不进入读者目录、检索和离线下载，上游文件与维护构建仍保留。详情原文中的来源、相关建议、术语和专题链接继续可用，路径式链接标签显示文章标题。

收藏独立保存本机并异步同步，保存失败不显示成功，各页面返回前台时刷新收藏状态。取消收藏保留同步用删除时间戳，旧云记录不会复活收藏。

历史打卡存储与云字段保留兼容，不删除用户旧数据，不提供操作入口。

首页、全书目录、建议详情、章节与专题长文支持微信好友分享和右上角朋友圈分享；阅读页有原生「分享给好友」按钮。分享标题使用原书标题，链接只带内容标识、条号或目录分类，不携带收藏、历史搜索、缓存和展开状态。接收方直接阅读对应内容，目录分类保留，摘要与导读保持默认折叠规则。未加载或无标题占位页隐藏分享菜单；跨版本兜底后分享当前实际内容。浏览器仅提供分享卡片及接收页面预览，微信发送和朋友圈单页模式需在开发者工具与真机验证。

阅读页分享封面在本机生成：原书标题最多三行，建议使用完整「说人话」、章节使用原书导读首段、专题使用原文首段，各摘录最多三行并标注出处及省略号。缺失摘要时只显示标题，不生成或改写摘要；不截取收藏与阅读状态。好友分享等待正在生成的封面，朋友圈使用已生成封面；接口不可用或超时使用静态书籍封面。浏览器复用同一画布排版。`python -X utf8 build/share_cover.py` 可重新生成首页、目录与异常兜底封面，需要 Pillow 和微软雅黑或 Noto Sans CJK 字体。朋友圈单页模式不初始化登录态云开发或同步收藏；云端正文通过微信底部「前往小程序」继续读取，不改变云资源访问权限。单页内的跳页、外链复制与收藏操作提示进入完整小程序，术语释义仍可本机查看。

筛选使用草稿，应用后搜索一次，关闭则丢弃草稿；关键词清空保留筛选，最近 6 个关键词保存在本机。请求序号忽略过期搜索结果。收藏正文获取失败时保留摘要或节号、条号占位，可阅读和重试。

建议卡片只使用完整原文摘要，不以搜索命中片段或旧版首句代替。详情优先显示本机摘要缓存，保留其中原有的链接与术语；无缓存时仍显示节号、条号和收藏操作。分页与重试的过期补全也会被忽略。

## 本地预览

`interaction-c.html` 演示完整目录、专题长文、原文摘要与展开、筛选、术语和收藏。包含固定版本的 676 条建议、34 节目录、9 篇原书专题，使用独立本机存储，不连接云端；收藏及链接处理复用小程序代码，CSS 从实际 WXSS 转换。

运行 `python -X utf8 build/parse.py` 构建本机内容，再运行 `python -X utf8 build/prepare_interaction_preview.py --write-demo` 和 `node build/preview_interactions.js` 更新演示数据、运行时代码与样式，从 `design/` 启动本地 HTTP 服务。构建只改变本机产物，不更改已部署内容。未来检索语料只收录正文与专题长文，客户端同时过滤旧云端响应中的过程材料。

内置 `pick-summaries.js` 只包含本版本推荐的完整“说人话”纯文本；原有内容构建会同时生成它，避免离线首屏只能显示旧版首句截取。摘要缓存按内容版本隔离。

## 验证

行为测试覆盖阅读导航、行动模块移除、推荐不受历史数据影响、收藏刷新与保存失败、冷启动补传、原文默认折叠、无重复请求、离线占位、搜索响应乱序、筛选应用取消和搜索历史。另运行历史数据兼容、合并、配色、WXML 结构及小程序静态检查。

浏览器演示需检查浅色与深色、375px 与 320px 的无横向溢出。微信原生渲染、键盘和真机安全区仍需在开发者工具及设备验证；浏览器演示不能代替真机结果。不提交、不发布、不部署云函数。
