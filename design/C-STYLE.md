# C 风格全站改版

用户已选择 C 风格，并确认覆盖全部 11 个页面及公共组件。

## 设计

- 黑白暖底、黄色重点卡、橙色交互、粗黑体标题、4rpx 方角和实线边框。
- 黄色用于首页建议和详情摘要；长文正文使用中性底色、30rpx 字号及 1.85 行距。
- 操作色与证据色独立；A/B/C、争议、性价比保留原有含义，浅暗两套文字对比度均至少 4.5:1。
- 首页呈现选中草图的问候标题与检索前置，问题分组仍可展开查看原有全部问题。
- 保留数据、云函数、事件处理、离线状态及进度，导航和底部操作条避开安全区。
