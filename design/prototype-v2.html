01 · 重设计的四个判断

现有设计语言（宋体承载内容、等宽承载数据、颜色只承载语义、找不到出处就不画） 是这本书的身份，全部保留。改的是信息的顺序和层级，不是风格。

首屏
从「书的目录」改为「今天该做的一条」——首屏唯一的大块，直接带加清单动作。
找问题
34 个问题按处境分五组（身体 / 习惯 / 钱 / 关系 / 精力），不再是一条平铺长列表。
条目详情
「说人话」上移到首屏第一块；成本签跟在结论后；收益/成本/来源依次展开。
清单
从「收藏 + 打卡」改为行动看板：今天 / 稍后 / 已完成 / 收藏，配连续天数。
离线
从首页第 6 屏的设置项，提升为常驻状态条 + 全屏进度 + 完成徽章。
版本
用「2026 年 10 月 9 日 · 676 条」说话，提交号留给「版本与更新」详情页。

05 · 组件：成本签与两轴标注

成本签（钱 / 时间 / 毅力 / 收益 / 口径）是产品的指纹，任何列表行都带着它， 让「零成本高收益」在滚动中一眼可辨 —— 绿色即「不用花什么」。 证据徽章与性价比条保持正交，不合成一个分数（合成会丢掉「数字可信度」与「值不值得」的区别）。

06 · 落地顺序

批次内容理由
第一批首页重构 + 问题分组 + 详情结论上移 + 清单改行动看板四者共享同一份字段变更，一起改一次联调
第二批离线状态条与全屏下载 + 检索分层 + 我的页重排 + 字号上调 + 埋点互相独立，可并行
